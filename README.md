# 직업전쟁 (Job Fortress)

미사일 없는 포트리스. 직업마다 던지는 물건이 다릅니다.

**플레이:** https://job-fortress.vercel.app

- **김결재** 야근 직장인 · 서류뭉치
- **나백수** 백수 · 슬리퍼 (한 번 튕김)
- **황금고** 재벌 2세 · 금괴 (무겁고 아프게)
- **송팔로워** 인플루언서 · 링라이트 (넓은 폭발)
- **박취준** 취준생 · 자소서 비행기 (멀리 활강)
- **차아아** 카페 알바 · 아이스아메리카노 (맞으면 다음 턴 힘이 약해짐)

## 실행

`index.html`을 브라우저로 열거나, 폴더에서 로컬 서버를 켜면 됩니다.

```
python -m http.server 4173
```

## 조작

- 위아래 화살표 또는 각도 버튼
- 좌우 화살표 또는 걷기 버튼 (MOVE 게이지가 짧음)
- 스페이스 / 발사 버튼 꾹: 힘 모으기, 떼면 발사
- 컴퓨터·휴대폰 브라우저에서 바로 플레이
